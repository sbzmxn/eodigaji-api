# 평가 결과

> 측정일 2026-11-11. 데이터: 한국관광공사 국문 관광정보 서비스_GW(KorService2), 전국 관광지 12,545건.
> 재현: `pytest`, `pytest -m integration`, `python scripts/check_locations.py`, `python scripts/alias_quality.py --model <이름>`.

## 1. 출발 좌표 7곳 × 운전 시간 4단계

`/keywords` 와 `/recommend`(키워드 없이)를 28개 조합에서 실제 서버 구성으로 호출했다.

**결과: 56/56 정상 응답(200), 실패 0건.** `/recommend` 응답 시간 40~420ms(템플릿 가명, 상세 캐시 상태에 따라 다름).

반경 안 후보 수와, 후보가 3곳 미만이라 `/keywords` 에서 꺼지는 키워드:

| 출발 | 15분 | 30분 | 60분 | 120분 |
|---|---|---|---|---|
| 서울 강남 | 95 · 바다 | 517 · 바다 | 1,533 | 2,936 |
| 서울 도심 | 313 · 바다 | 567 · 바다 | 1,535 | 2,840 |
| 대구 | 92 · 바다 | 190 · 바다 | 526 · 바다 | 1,941 |
| 부산 해운대 | 58 · 호수·강, 숲, 고즈넉 | 147 · 호수·강 | 444 | 1,459 |
| 강릉 | 34 · 바다, 호수·강, 전망, 노을 | 89 | 273 | 891 |
| 안동 | 25 · 바다, 호수·강, 숲, 전망, 노을 | 43 · 바다, 호수·강, 숲, 전망, 노을 | 218 · 바다, 전망 | 1,351 |
| 제주시 | 49 · 숲 | 97 | 436 | 524 |

- 반경(직선) = 처음 30분 30km/h, 이후 60km/h로 가는 거리 ÷ 1.3 → 15분 5.8km, 30분 11.5km, 60분 34.6km, 120분 80.8km.
- 노을·야경은 후보 수와 별개로 도착 예상 시각(일몰 60분 전~20분 후 / 일몰 30분 후~23:00)으로 켜고 끈다.
- 결론: 대도시는 15분부터 대부분 키워드가 쓸 만하다. 중소도시(안동·강릉)는 30분 이하에서 키워드가 많이 꺼지므로 시연 좌표·시간 선택 시 고려한다.

## 2. 섬 규칙

| 규칙 | 문제 (실측) | 처리 | 적용 후 |
|---|---|---|---|
| 다리로 이어지지 않은 땅 | 제주시 120분 → 완도 섬 25곳, 서울 120분 → 옹진 섬 48곳이 후보에 섞임 (배로만 갈 수 있음) | 제주 본섬·추자도·우도·울릉도·옹진군 섬(영흥면 제외)을 별도 땅으로 정의. 출발지(가장 가까운 관광지 15km 이내 기준)와 같은 땅의 후보만 추천 | 제주시 120분 후보 524곳 전부 제주 본섬, 서울의 옹진 섬 후보 0곳 |
| 강·호수의 섬 | 서울에서 '바다'를 고르면 한강의 반포 서래섬이 추천됨 | 섬은 같은 시·군·구에 해변·항구·해안절경·등대가 있을 때만 '바다', 없으면 '호수·강' | 섬 274곳 중 12곳이 '호수·강'으로 바뀜(서래섬, 하중도, 자라섬, 남한강 섬 등) — 모두 실제 하천·호수·운하의 섬 |

한계: 목록에 없는 다른 비연륙 섬은 걸러지지 않는다. 발견되면 `config/settings.yaml` 의 `landmasses` 에 추가한다.

## 3. 가명 생성 모델 비교

조건: 같은 20건, LLM 입력은 시간대·'힐링'·무작위 느낌 단어뿐(장소 정보 없음). 모델을 하나씩 단독으로 GPU 에 올려 측정. 검증 = JSON 형식, 한글 5~20자, 같은 어절 반복 금지, 금지어(실명 조각·지명·장소 유형어).

| | llama3.2:1b | gemma3:4b | qwen2.5:7b |
|---|---|---|---|
| JSON 유효율 | 97% | 100% | 97% |
| 검증 통과율 (시도 기준) | 50% | 69% | 58% |
| 최종 LLM 채택 | 18/20 | 16/20 | 18/20 |
| 실명 누출 | 0/20 | 0/20 | 0/20 |
| 지연 평균 / 최대 (요청당) | 246 / 502ms | 461 / 811ms | 802 / 8,059ms (8초 타임아웃 1회) |
| VRAM | 1.4GB | 2.7GB | 4.4GB |
| 자연스러움 | 낮음 ("고구마의 어둠", "안나스스카") | 중상 ("고요한 발견", "밤의 정적") — 표현 반복 경향 | 상 ("밤의 포근함", "새로운 이정표", "비밀의 쉼") |

| 모델 | 라이선스 | 앱마켓 출품(서버 호스팅) 시 |
|---|---|---|
| llama3.2:1b | Llama 3.2 Community License | 상업 이용 가능(월 사용자 7억 초과 시 별도 허가). "Built with Llama" 표시 의무 |
| gemma3:4b | Gemma Terms of Use | 상업 이용 제한 문구 없음. API 호스팅도 '배포'로 정의 → 이용약관에 사용 제한 조항 포함·고지 의무 가능 |
| qwen2.5:7b | Apache-2.0 | 상업 이용 가능, 사용자 수 제한 없음 |

결론: 시연 기본값은 **템플릿 전용**(`alias_mode: template`, LLM 미호출). 고정 29개 + 시간대 수식어 × 감성 명사 조합(시간대별 340개 이상), 모두 같은 금지어 검증을 통과한다. LLM 을 쓴다면 품질·라이선스 모두 qwen2.5:7b 가 가장 낫고, 지연 스파이크 원인 확인이 선행 과제다. (라이선스 판단은 법률 자문이 아님)

## 4. 개인정보 검증 (좌표 미저장)
